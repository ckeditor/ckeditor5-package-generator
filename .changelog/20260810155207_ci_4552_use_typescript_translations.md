Updated generated packages to store translation sources as TypeScript modules.

When upgrading a package generated by an earlier version, migrate its `lang/translations/*.po` files to `lang/translations/*.ts` modules and update the `translations` plugin source in `vite.config.*` to `**/lang/translations/*.ts` before running `translations:synchronize`. Otherwise, existing translations will not be read.
