Generated packages now use Vitest v5 (`vitest`, `@vitest/browser-webdriverio` and `@vitest/coverage-istanbul` v5.0.0 or later) instead of Vitest v4. This applies to both the JavaScript and TypeScript templates.

The Vitest root in the generated `vite.config` now points to the package directory instead of `sample/`, so the coverage report includes the plugin sources from `src/`. Vitest v5 resolves the `coverage.include` patterns relative to its root and with the previous root the report was empty.
