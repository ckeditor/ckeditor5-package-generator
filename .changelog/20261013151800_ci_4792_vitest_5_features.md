Generated packages now run their tests in Chrome through `@vitest/browser-playwright` and `playwright` instead of `@vitest/browser-webdriverio` and `webdriverio`. The Vitest team no longer maintains the WebdriverIO provider. This applies to both the JavaScript and TypeScript templates.

The `.gitignore` file of generated packages now lists the `.vitest/` directory, where Vitest v5 saves reports and screenshots of failed tests.
